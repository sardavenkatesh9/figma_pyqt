# User guide

## Start the workbench

```bash
figma-to-pyside6 gui
```

## Verify, select, and generate

Paste a Figma design or file link, enter a personal access token, and choose **Verify link**. Once the file is verified, select the frames to include, set a project name and output directory, then choose **Generate project**. The token is cleared after the request and is not stored.
